Hark, a voice and chat desktop app for your Copilot tools

A native .NET Windows app that sits in the tray, wakes on “Hey Chat”, and runs your prompts through GitHub Copilot with your Azure DevOps and Purview MCP tools. No VS Code needed. “Hark” is a working name. The mock below is clickable; all data in it is example data.

What each requirement needs

RequirementHowStatus
Runs without VS CodeThe Copilot SDK for .NET brings its own runtime into the app. Nothing else to install.Checked in .NET SDK 1.0.29
Only your PAT is usedToken passed explicitly, with the “use logged-in user” option off, so no other GitHub login on the PC can be picked up.Checked
Model pickerThe SDK returns the models your plan allows, with each one’s cost multiplier. The app lists exactly that.Checked
Your MCP toolsLocal-process and HTTP servers with environment variables. The app reads the VS Code file directly, so martechchat and ado-mcp work with no re-entry.Checked
Saved chatsLocal database for the History tab. The SDK can resume a past session with its context.Checked
Custom wake phrasesherpa-onnx keyword spotting. You type the phrase; no model training. Short phrases can mis-fire, so there is a sensitivity setting and a shortcut as backup.Needs tuning on real mics
Speech in, text outLocal speech-to-text model, one-time download. Answers are always text; nothing is read aloud.Feasible
Microsoft sign-inYour tool signs in itself, in the browser, exactly as today. No app registration and no service principal. One small step makes the login last across restarts: az login once, or about 15 lines in the tool.Code reviewed
Org policyYour GitHub org must allow Copilot CLI/SDK use and fine-grained PATs with the Copilot Requests permission.Confirm with a 1-day spike

One thing to watch: Copilot moved to usage-based billing in June 2026. If your org admin has enabled paid overage, heavy use could bill beyond the plan. Ask them to keep the overage budget at zero and the app can never cost more than the seat. The app shows a usage meter either way.
