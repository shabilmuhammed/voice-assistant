What changes

Layout

  • Recent chats live in the sidebar, so going back to one is a single click. History stays as the full, searchable list.
  • The title bar merges into the app. No separate Windows strip above the content.
  • The message box floats over the conversation as one rounded card holding attachments, screen, microphone, model and send.
  • Status moves to the sidebar foot: Copilot, tool servers and voice, each with a live dot.

Conversation

  • Your messages are quiet tinted bubbles; answers sit on the page without a box, so long answers read like a document.
  • Tool calls fold into one line (“Used 2 tools in 1.9 s”) that opens to show each step.
  • Code blocks get a header with the language and a Copy button. Answers get Copy and Try again on hover.
  • Generated files are tiles you click to open.
  • A new chat opens with four starting points drawn from your own tools.

Look

Colour

Canvas Surface Ink Signal Your messages

Cool neutrals with one accent, the cyan already in the app icon. The accent is spent on the send button, focus, links and the orb, and nowhere else. Light and dark are both designed; this page follows your theme.

Type and shape

  • Geist for the interface and Geist Mono for code only. Both are free to bundle with the app.
  • Three corner sizes by role: small controls, cards, and the floating message box.
  • The orb is the one expressive element. It appears on a new chat and in the voice panel, and speeds up with your voice.

How it gets built, and what to expect

Approach

  • Same WPF app and the same logic underneath. Only the views, styles and control templates are rebuilt.
  • Built in four passes, each with build screenshots for you: shell and sidebar, conversation, message box, then Settings, Connections and the voice panel.
  • No new paid components. The fonts are open source.

Honest limits

  • This mock is a web page. The WPF result should match its layout, colour and type closely, but text rendering and some easing will differ slightly.
  • The orb’s soft blur is the costliest effect. If it stutters on your laptop it falls back to a simpler pulse.
  • I can check still screenshots from the build, not motion. You would be the one judging how the animations feel.
